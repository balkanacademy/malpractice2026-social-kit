MALPRACTICE 2026 LINKEDIN SOCIAL KIT — FIVE-PERSON TEST

WHAT THIS TEST DOES
- It is a static website. It has no LinkedIn app, server, database, or password screen.
- Desktop: downloads the personalised PNG and opens LinkedIn with the optional caption filled. The visitor adds the downloaded image.
- Android: copies the optional caption and opens the phone share sheet with the full PNG.
- iPhone/iPad: gives four clear manual steps: save the image to Photos, copy the optional caption, open LinkedIn, then add the photo and paste the caption.
- Visitors can switch manually between Desktop, Android, and iPhone/iPad instructions.

IMPORTANT
- This package contains only five test records.
- The QR code is intentionally hidden until the final public website address is known.
- Do not open index.html directly from a computer folder. The site should be uploaded to a web host so clipboard and mobile sharing features work correctly over HTTPS.
